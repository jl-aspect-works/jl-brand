# Brand Guide

## Approved visual system

The JL Aspect Works identity uses a rounded-square JL icon with an organic waveform, a dark monochrome palette, and a horizontal wordmark in which **ASPECT** carries the strongest visual emphasis and **WORKS** is lighter and widely spaced.

## Approved text

**Company:** JL Aspect Works

**Organization tagline:** Intelligent tools for modern recording and mixing studios

**Footer line:** Engineering better studio workflows.

## Usage

- Use dark assets on black or charcoal.
- Use light assets on white or pale neutral backgrounds.
- Use transparent assets only on backgrounds that provide sufficient contrast.
- Preserve the included safe margins.
- Do not recolor, stretch, compress, rotate, or redraw the mark.
- Do not replace the waveform or change the JL letterforms.

## Product family

- JL Mixing Studio
- JL Mixing Automation

Use `by JL Aspect Works` as secondary attribution.
